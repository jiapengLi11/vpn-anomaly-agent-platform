## 后续顺序

1. 获得合法独立样本后执行双人复核，禁止把自编开发集当业务效果。
2. 扩充独立检索集，对比 BM25 与向量召回/RRF，禁止直接在开发集上调门槛。
3. 将本地 MCP Bridge 接入正式 stdio/streamable HTTP 传输，继续复用 Tool Router 准入；不让外部传输绕过权限和计费。
4. 接入可公开的分类器与样本，扩展 PCAP 到报告的公开端到端演示。

上述顺序为开发计划。当前测试通过率不能作为检测准确率、检索质量或幻觉率；也未建立 65% 到 88% 的实验依据。
