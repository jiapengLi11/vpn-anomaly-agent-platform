# 实现状态与下一步

此表针对公开仓库。GitHub Pages 执行浏览器检索并显示预生成分析报告；运行 Python CLI 或 API 才会现场执行 LangGraph。

| 能力 | 当前实现 | 剩余工作 |
| --- | --- | --- |
| Vue 工作区 | 任务、报告、证据、Agent 轨迹、知识搜索 | 在线创建任务需要完整平台后端 |
| Agent | 五节点 StateGraph、无候选短路、异常降级 | MCP 工具协议、持久化恢复、人审中断 |
| 文档检索 | 3 篇自编 Markdown、6 个切片、BM25、来源哈希；浏览器和 Python 排序一致 | 多格式解析、向量召回、RRF、重排、权限过滤 |
| 模型分析 | 可注入 analyst 接口，默认确定性演示 | 外部 LLM 适配、超时与费用记录、真实输出验收 |
| 分类器 | 通用接口与合成输出 | 可公开训练数据、替代分类器、推理和指标验收 |
| 证据门禁 | 类型、引用存在性、调查会话归属和强度检查 | 引用文本是否支持结论的语义校验；更多恶意输入测试 |
| 数据保护 | 结构化路径剔除、地址及指定域名字段化名 | 任意自由文本敏感内容识别；当前不保证完整 DLP |
| 图谱 | 未包含图谱运行依赖 | 公开实体关系种子、图谱查询和集成测试 |
| 评测 | 功能回归与跨语言检索一致性 | 人工标注集、Recall@K/MRR、结论支持度、成本延迟实验 |

## 后续顺序

1. 接入可配置外部 LLM，以自编文档和合成候选验证检索增强报告，记录模型版本、耗时、调用状态。
2. 增加小型人工标注检索集，对比 BM25 与向量召回，报告样本数和失败案例。
3. 将现有工具接口包装为 MCP，补调用轨迹和工具参数校验。
4. 接入可公开的分类器与样本，扩展 PCAP 到报告的公开端到端演示。

上述顺序为开发计划。当前测试通过率不能作为检测准确率、检索质量或幻觉率；也未建立 65% 到 88% 的实验依据。
